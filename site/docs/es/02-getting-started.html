2. Primeros pasos

Requisitos previos

Instala Rust y una toolchain de compilación C funcional. La toolchain C compila el runtime de Lua 5.4 vendido.

Compilar

Desde el directorio del proyecto:

cargo build --release

Esto crea target/release/tandem.

Compilar y ejecutar un programa

Los archivos fuente de Tandem usan la extensión .tdm. La compilación escribe un archivo .lua junto al fuente y luego lo ejecuta:

cargo run -- examples/hello.tdm
#    Compiling examples/hello.tdm
#     Finished examples/hello.lua

O invoca el binario compilado directamente:

./target/release/tandem examples/hello.tdm

Elige otra ruta de salida pasándola como segundo argumento; el directorio de salida ya debe existir:

cargo run -- examples/hello.tdm build/hello.lua

Antes de compilar, Tandem comprueba la ruta de salida. Un archivo .lua existente se sobrescribe solo si empieza con la cabecera generada por Tandem (-- Generated by Tandem ...); de lo contrario el comando se niega a sobrescribirlo. Esto evita que la salida generada reemplace archivos Lua escritos a mano.

Comprobar sin ejecutar

--check analiza y comprueba los tipos del archivo sin escribir ni ejecutar ningún Lua. En caso de éxito imprime la ruta:

cargo run -- --check examples/hello.tdm
#     Checking examples/hello.tdm
#     Finished examples/hello.tdm

Para instalar las dependencias declaradas en mlua-pkg.toml, ejecuta tandem pkg install desde el directorio del proyecto. Consulta Paquetes LuaRocks para el formato del manifiesto y el comportamiento en runtime.

Dividir un programa en varios archivos

Usa require con la sintaxis de llamada de Lua. Las rutas de módulos usan / y, preferiblemente, una extensión explícita .tdm o .lua:

module greetings = require("greetings.tdm");
module helper = require("lua-helper.lua");

print(greetings.hello("Lua"));
print(helper.hello("Lua"));

El tipo module declara un enlace cuyo tipo se infiere del archivo requerido. También se admiten las formas estilo Lua:

local greetings = require("greetings.tdm");
print(require("greetings.tdm").hello("Lua"));

Una ruta sin extensión se resuelve como <path>.tdm, luego <path>.lua, luego <path>/init.tdm y <path>/init.lua, relativa al directorio del archivo de entrada principal. Los nombres punteados estilo Lua como lib.math también resuelven a lib/math.tdm y a los otros candidatos, por compatibilidad con paquetes Lua. Las rutas que empiezan por ./ o ../ se tratan como rutas relativas explícitas.

Cada módulo .tdm alcanzado mediante require se compila e incrusta en el Lua generado bajo package.preload. Los módulos .lua no se compilan: Lua los carga en tiempo de ejecución desde el directorio del archivo de entrada. Sus valores se tipan dinámicamente, por lo que usa as type al asignarlos a variables estáticamente tipadas. Una ruta de módulo no encontrada localmente se deja al sistema de paquetes de Lua, como los módulos instalados con tandem pkg install. Una ruta faltante con extensión explícita o un prefijo explícito .//../ es un error de compilación.

Como en Lua, un require("greetings.tdm"); independiente solo carga el módulo y no crea una variable. Enlaza el resultado con module name = require("..."); o local name = require("..."); para usar sus exportaciones.

Consulta examples/modules.tdm para un programa que importa tanto un módulo Tandem como un módulo Lua.

Importar la biblioteca estándar

Los paquetes de la biblioteca estándar de Lua no están en alcance por defecto. Importa los paquetes que use el programa en el nivel superior y luego accede a sus miembros:

import string, math;

str upper = string.upper("lua") as str;
float root = math.sqrt(16.0) as float;

Los miembros de los paquetes importados son dinámicos, por lo que se necesita una aserción as type al asignar uno a una variable tipada. Las funciones base de Lua como tostring y pairs necesitan import base;. Consulta Expresiones para la lista completa.

Ejecutar archivos Lua ordinarios

Pasa un archivo .lua para ejecutarlo directamente en el runtime embebido. Los argumentos adicionales llegan al script a través de la tabla arg de Lua:

cargo run -- examples/script.lua first-arg second-arg

Consulta Línea de comandos para la referencia completa de la CLI, incluido el manejo de errores y los códigos de salida.
