What is Tandem?

Tandem is a small, statically typed, C-style language that transpiles to Lua 5.4. Source files use the .tdm extension. Declare functions with fn, classes with class, and run the generated Lua through the embedded runtime — no separate Lua executable required.

The compiler is written in Rust and checks types, control flow, and inheritance before emitting readable Lua. It supports modules, generics, interfaces, mixins, traits, enums, unions, pattern matching, closures, optional types, and operator overloading.

A first program

int playerX = 100;

fn movePlayer(int speed = 10) -> int {
    return speed + 1;
}

playerX += movePlayer(20);
if (playerX > 100) {
    print("Player moved!");
}

Save it as hello.tdm, then run it with cargo run -- hello.tdm.
