# TypeLua documentation

TypeLua compiles `.tlua` source files to Lua 5.4 and can run either generated Lua or ordinary `.lua` files through its embedded runtime.

- [CLI guide](cli.md): build, compile, check, and run source files.
- [Language guide](language.md): types, syntax, comments, and current limitations.
- [Runtime and Rust API](runtime.md): use the compiler and embedded Lua runtime from Rust.
